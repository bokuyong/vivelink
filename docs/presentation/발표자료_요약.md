# clodock 중간발표 요약

## 발표 톤

- 새로 설계한 앱이라는 점을 강조
- 하드웨어 지연에도 개발이 멈추지 않았다는 점을 강조
- 현재는 토스 자동화부터 완성도를 올리는 단계라고 설명

## 핵심 메시지

1. clodock은 음성 기반 Android 제어 및 자동화 앱이다.
2. 현재는 대표 시나리오로 토스 송금 자동화를 우선 구현 중이다.
3. 하드웨어 구매 지연으로 사비로 3종 기기를 확보했고 Android 세팅을 진행 중이다.
4. 앱은 폰-폰 환경에서 먼저 테스트했으며, AI 자연어 판단 정확도는 계속 수정 중이다.
5. 이후 하드웨어 연동과 기능 확장을 통해 범용 앱 제어로 확대할 예정이다.
